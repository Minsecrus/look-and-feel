# 表格行悬停时，进度条空槽隐身（`#EAECEF` 叠 `#ECECEC`）

- 相关章节：`style`、`density`、`system`

## 场景

资源用量表格里，每行都有 `0 / 128 核` 的文字和一条浅灰空槽进度条。平时白底上进度条清晰可见；鼠标悬停到某一行时，整行背景变成浅灰 `#ECECEC`，而进度条空槽本身是写死的实色浅灰 `#EAECEF`——两个颜色的 RGB 分别是 `(236, 236, 236)` 和 `(234, 236, 239)`，对比度约 `1.005 : 1`，空槽直接融进背景里彻底隐身，第一眼像这一行少了进度条。

## 踩了哪些坑

- **实色浅灰嵌套撞色（`style`）**：组件各自挑了一个在白底上顺眼的实色浅灰，一放进 hover 行、斑马纹、选中态或灰底卡片里，色差归零变成“保护色”。
- **同类高发场景**：进度条空槽、灰色 Tag / 胶囊、行内 `code` 底色、次要按钮、骨架屏，一旦嵌在带底色的容器里都容易失踪。
- **靠状态补丁治标不治本（`system`）**：如果用 `.row:hover .track { background: ... }` 挨个打补丁，换到选中态、灰卡片或暗色模式又会漏。

## 怎么改才顺手

- 浅层底槽和弱强调填充优先用**半透明叠色**（如亮色下 `rgb(0 0 0 / 8%)` 或 `rgb(15 23 42 / 8%)`，暗色下 `rgb(255 255 255 / 12%)`）：落在白底上是柔和浅灰，落在 `#ECECEC` 的 hover 行上会自动叠加加深一档（约 `#D9D9DC`），不管套进什么底色都能自然拉开层级。
- 必要时补一圈极淡半透明内描边（`inset 0 0 0 1px rgb(0 0 0 / 6%)`）兜底边界。
