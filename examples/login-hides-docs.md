# 登录后文档入口消失（登录撤梯子）

- 相关章节：`hide`、`layout`、`empty`

## 场景

用户登录后想了解平台怎么申请和使用，翻遍界面找不到说明书，只好去问维护者。维护者答“看主页右上角文档，或者直接访问 `/docs`”。结果用户发现：文档入口只挂在未登录的官网落地页右上角；一旦登录进工作台外壳，入口就彻底消失了。

## 踩了哪些坑

- **两张皮割裂，破坏空间恒常性（`layout`）**：未登录落地页和已登录工作台各自一套导航外壳，登录后把原有的全局路标直接蒸发；很多站点甚至连点 Logo 都会重定向回工作台，用户想退回“主页右上角”都回不去。
- **把最需要文档的人挡在文档外面（`hide`）**：把文档、帮助、定价、更新日志当成“给未登录路人看的门面”，却忘了真正卡壳查说明书的恰恰是已经登录进来干活的人。
- **首次冷启动没递线头（`empty`）**：新用户登录后面对空白台面不知从何下手，界面上没有顺手给出“查看文档 / 从这里开始”的入口。
- **维护者的登录态盲区**：维护者记住了 `/docs` 路径或在未登录态看过入口，没意识到已登录用户的界面里这个按钮早就没了。

## 怎么改才顺手

- 文档、帮助、反馈、状态页属于常驻安全网，登录进工作台后绝不能消失——顶栏放不下就固定收进侧栏底部或头像菜单的“帮助 / 文档”里。
- 首次登录的空状态里顺手递出“快速上手”或文档入口。
