# 输入

- 能选就不填，能猜（给默认值）就不问
- 输入不只是打字填表：拖拽文件、扫码拍照、语音、命令面板（Cmd+K）和参数补全都是输入，原则都是让机器多做一步、人少敲一个字
- 标签（label）老实待在输入框外面，别拿 placeholder 当标签
- placeholder 放格式示例（如 you@example.com），别写重复废话
- 输入框宽度暗示预期长度：验证码框窄、邮箱框宽、长文用多行域
- 自动聚焦：只在打开这一刻唯一目的就是输入时才自动聚焦
- 支持回车提交、合理的 Tab 顺序、长文本支持自动增高
- 移动端唤起对应键盘（数字、邮箱、电话、搜索）与浏览器自动填充（autocomplete）
- 输入宽容：自动忽略卡号、手机号里的空格和横杠，别逼用户按机器格式手删
- 分段验证码或短码支持一次性粘贴整串
- 识别永远优于回忆（Recognition over Recall）：别让用户凭空默写格式、命令或上次查过的关键词，直接给出候选选项、最近记录和自动补全，让眼睛扫到就能选
- 加粗或大字号输入框（如命令面板、顶部搜索栏）别让 placeholder 盲目继承父级字重：placeholder 是辅助提示，输入内容才是生效数据；把 placeholder 主动退回常规字重，用“颜色 + 字重”双通道拉开虚实，尤其在半透明或弱对比底色上更稳，避免出现“又粗又淡”的笨重提示词
