# 空白

- 空状态不是画张插画写句“暂无数据”就算交差
- 空状态不只是列表页的事：软件刚启动的空白工程页、硬件未连接状态、命令行不带参数时的使用提示，都要给人一条往下走的路
- 区分四种空：首次使用、搜索无结果、全部清零、出错或无权限
- 首次冷启动：说明这里以后会长什么样，给示例模板或“新建第一条”动作
- 搜索 / 筛选无结果：写清哪个条件没匹配到，给放宽或清空按钮
- 全部完成 / 清零：给一点轻盈的完成感，别显得像出故障
- 出错或无权限导致的空：说清原因，给出重试按钮或申请入口
- 图片或头像缺省与加载失败兜底：显示首字母底色或稳住原高度，别露出裂图图标
- 列表只有 1～2 条数据时的“半空状态”也要顺眼顺手
- 新手路标要轻量、随时可跳过且别反复弹：别在用户刚进来想干活时硬塞十步强遮罩教程，好引导藏在顺手的空状态、示例内容和低打扰提示里
