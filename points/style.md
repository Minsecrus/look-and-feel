# 风格

- 先做对内容、划分和尺度，最后再谈风格
- 不用纯黑 #000 和死白刺眼，给中性灰带一点微弱倾向
- 文字三档灰度：正主、说明、辅助元数据
- 灰度一拉，很多多余的加粗和标签都能删掉
- 表面层级：底色、浅层、抬起、下沉
- 表面层级借的是物理世界的叠放直觉：靠明暗和边界分清谁在上面、谁被框住，网页、桌面窗口和移动端卡片共用同一套空间纵深
- 用 1px 低透明度边框代替厚框线和黑阴影
- 什么时候才该用阴影：浮层、弹窗、下拉菜单
- 全站主色克制到只有一个，留给唯一主角和焦点
- 按钮主色与文字链接色的对比度分离
- 语义色（红 / 黄 / 绿）只在真的出事或表状态时出现
- 圆角嵌套关系：外圆角 = 内圆角 + 内边距
- 一致的线宽、图标笔画粗细与控件形状
- 同一个界面别混用细线、实心图标和彩色 Emoji
- 图片与头像加 1px 极淡半透明内描边，防止浅色图边缘融进背景
- 字别随便压在图片上：必须放就压渐变暗罩，更稳的是挪到图片下面
- 克制的微动效：快进快出、100～200ms，不晃眼不抢戏
- 和宿主平台相处：系统原生控件（滚动条、弹窗、系统字体）自有习惯，别为了统一风格硬画一套别扭假壳
- 风格就是全站遵守同一组小约束，不是叠特效滤镜
- 对比度不是越高越好：暗光下纯黑底配纯白字容易产生光晕效应（Halation）导致字边发虚刺眼，深灰底配柔白往往更耐看
- 颜色不能是唯一信息载体：红绿灯除了颜色还有上下位置，报错除了变红还得配图标和文字，防止色弱人群、黑白打印或强光反光下直接抓瞎
- 动效要有物理惯性且“进稳出快”：现实里没有零毫秒启停（少用线性匀速），弹出可带轻微阻尼，关闭和退场必须干脆利落绝不挡路
- 动效必须可打断：刚点开抽屉就反悔往回划，动画必须当场掉头跟手，别强迫用户干等动画播完才肯响应下一次操作
- 浅层控件底色优先用半透明叠色而不是写死实色灰：进度条槽、灰标签、骨架屏和弱按钮用 `rgb(0 0 0 / 8%)` 这类半透明色，放进 hover 行、斑马纹或灰底卡片里会自动加深一档，不会跟父容器撞色隐身
- 风格不只体现在配色和圆角，还体现在全站统一的“松紧节奏”：标题字距、留白和控件内边距的张力要同频
