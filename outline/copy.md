# 文案

- 按钮写具体动词（保存修改 / 永久删除 / 放弃草稿），少写“确定 / 取消”
- 别用图标硬代文字：除了搜索、关闭、返回等极少数公认符号，图标配文字或直接写字更清楚
- 确认弹窗的按钮必须顺着问题写，别让人猜“取消到底是取消什么”
- 报错必须说清三件事：出了什么错 + 为什么 + 现在怎么修
- 不把内部错误码、英文堆栈或指责用户的语气甩到脸上
- 全站叫法统一：同一个对象别一会叫“项目”，一会叫“工作区”，一会叫“空间”
- 能靠界面位置和状态看懂的字直接删掉，别写三行免责声明式废话
- 时间和数字贴近人话（“3 分钟前”与悬停完整时间）
- 中文标点、中西文空格、单位与省略号细节
